
# CPS222_HW3

A 3D wireframe rendering application built from scratch in C++ using X11.

## Requirements

- Linux / WSL
- g++ (supporting C++17)
- libX11-dev
- make

## Build and Run

```bash
make
./3d-floating-shape

```

## Controls

* `1` - `8`: Switch 3D models
* `G`: Toggle ground grid
* `Left` / `Right`: Pan camera
* `A` / `D`: Rotate camera yaw
* `ESC`: Exit
